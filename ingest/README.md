# Ingest

This directory receives new Sanskrit files to be added to the Dharmamitra/Dharmanexus corpus.

Files are organized in batches. Each batch is a subdirectory containing the new texts along with any accompanying metadata. Once a batch has been processed and its contents incorporated into the main data (segments, `SA_files.json`, etc.), the batch directory is deleted.

Do not rely on files here being present long-term — this directory is a staging area, not a permanent store.
