Chapter 1

oṃ namo bhagavatyai āryakurukullāyai

naṣṭe gate cāntarhite ca tantre tārodbhave yogamahāsamudre /
tārārṇavo nāma mahādhitantro naṣṭe ca tasmin punar eṣa kalpaḥ // 1 // 

uddhṛtya tantreṣu ca vistareṣu yogān prayogān bahusattvahetoḥ /
lokeśvaraḥ kalpam idaṃ babhāṣe śṛṇvantu sarve kila bodhisattvāḥ // 2 // 

imaṃ nayaṃ sarvajanārthakāri lokaṃ vilokyāśaraṇaṃ mayādya /
triduḥkhaduḥkhena vidheyam etad grāhyaṃ bhavadbhir mahatādareṇa // 3 // 

sarvair idaṃ buddhagaṇaiḥ praṇītaṃ kalpaṃ tv idaṃ lokavikalpaśāntyai /
śrīpotale parvatake uvāca mañjuśriyā padmabhṛtā jayena // 4 // 

viṣkambhiṇā sāgarabuddhinā ca maitreyapramukhaiś ca gaṇaiś ca sarvaiḥ /
śruto hy ayaṃ dharmapadaprabandho 'numodito vandita eva mūrdhnā // 5 // 

bahulīkṛtaḥ sarvajinaurasaiś ca stuto 'thavā gītavareṇa vādyaiḥ /
nāṭyair vicitraiś ca prapūjur enaṃ yakṣāś ca mārāś ca salokapālāḥ // 6 // 

ṛkṣakṣitīśā ˈśanipāṇayaś ca vicītaraṅgeṣu ca ye vasanti /
nāgāṅganā ˈpāṅganirīkṣaṇejñāḥ pātālapālāḥ surasiddhakanyāḥ // 7 // 

gandharvarājñyaḥ kucalālasāś ca vidyādharīkiṃnarayoṣitaś ca /
yakṣāṅganāḥ parvataputrapautrā evaṃ vadanty aśaraṇā vayaṃ te // 8 // 

nātho ˈsy anāthasya hi lokanātha yenāsti buddhasya hi śāsane ˈsmin /
saukhyaṃ prajānāṃ mahad adbhutaṃ yat śrutvā gaṇasyāsya vacāṃsi nātho // 9 // 

mantraṃ svayaṃ vaśyakaraṃ babhāṣe tāḥ sarvanāryaḥ śrutamantrarājāḥ /
saukhyaṃ yayur bauddham anekakoṭyaḥ śukraṃ kṣarantyo ˈsusamā spṛhanti // 10 // 

vakrāvalokena nirīkṣayanti bhūmau patanti caraṇau skhalanti /
muñcanti śukraṃ valayanti rāgaṃ // 11 // 

evaṃ ca dṛṣṭvā surasundarīṇāṃ vacāṃsi nāthaḥ samayaṃ babhāṣe /
kurukullamantraṃ vaśakṛj janasya mantreṇa siddhasya paṭasya lekhyam // 12 // 

evaṃ tu śrutvā bhagavān triloke lokeśvaraḥ karma udājahāra // 13 // 

athātaḥ sampravakṣyāmi kurukullāyāḥ paṭakriyām /
yasyā likhanamātreṇa sādhakaḥ siddhim āpnuyāt // 14 // 

yena citrakareṇeha yayā tithyā ca velayā /
tad ahaṃ kalpayiṣyāmi yathā tārodbhavoditam // 15 // 

ātāmranayano yas tu raktapāṇis tathāṅghrimān /
gajākṣaiṇeyajaṅghaś ca tena lekhyā tu tāriṇī // 16 // 

vasantasyādime māsi aśokāṣṭamivāsare /
sārdhapraharavelāyāṃ netre lekhyā tu tāriṇī // 17 // 

trimadhurāśy amatsyādo madyamāṃsavivarjitaḥ /
raktāmbaradharo nityaṃ raktagandhānuliptakaḥ // 18 // 

maitryacittaṃ samutpādya prātaḥsnāyī śivālaye /
tricelaparivartī ca sa likhed vaśakāriṇīm // 19 // 

ekavaktrāṃ viśālākṣīṃ caturbhujāṃ kuṅkumopamām /
ṣoḍaśābdāṃ saśṛṅgārāṃ strīmāyāmadadarpitām // 20 // 

gaurakumārīkartitasūtreṇa paṭaṃ kāryaṃ; tayā ca tantravāyeṇa ca kṣīrānubhuktā // 21 // 

raktapadmāsanāṃ raktakañcukottarīyāṃ raktatāḍaṅkakirīṭinīm savye abhayapradāṃ dvitīye āpūritaśarām avasavye cāpadharāṃ dvitīye raktotpaladharām / ārolikmukuṭinīṃ kurukullācalaguhāntasthām // 22 // 

kurukullake rāhus tasyopari sapatnīkaḥ kāmaḥ kāmasyopari candramaṇḍalam tatra ca raktāravindāsanaṃ / tatrasthāṃ sarvacitrakalābhir bhagavatīṃ niṣpādya paṭaṃ pratiṣṭhāpya tasya paṭasyāgrato ˈṣṭādaśapūjāṃ kṛtvā śuklāṣṭamyāṃ yāvat paurṇamāsīṃ mantraṃ japet / anena tārāhṛdayena // 23 // 

oṃ kurukulle hrīḥ hūṃ svāheti mantreṇa // 24 // 
tato lakṣamātraṃ pūrvasevāṃ kṛtvā punaḥ kārtikasya vā mādhavasya vā āṣāḍhasya vā buddhaparvaṇyāṃ tithau prātaḥ snātaḥ poṣadhikaḥ sarvapūjāṃ nivedya śrāvakasaṅghāya bhojanaṃ dattvā paścād gaṇaṃ mantramahāyānikaṃ bhojayitvā yathāsiddhau vijñapya dakṣiṇāṃ dattvā ekāṃsottarāsaṅgī dakṣiṇaṃ jānumaṇḍalaṃ pṛthivyāṃ pratiṣṭhāpya yena śrāvakasaṅghaḥ / yena ca mantramahāyānarato gaṇas tān abhivandya kṣamāpya yatra paṭāvatāritā bhagavatī tenopagamya yathāsiddhyarthaṃ dhyānopeto vidyādharo ˈkṣaralakṣaṃ japet // 25 // 

aṃśena vardhate prajñā aparāṃśena vaśyakṛt /
aṃśenaiva tṛtīyena viṣākarṣī bhaven naraḥ // 26 // 

sarvasya lokasya bhavet sa pūjyaḥ strīṇāṃ madenāpi ca garvitānām /
yathecchayā mantradharo vibhuṅkte abhyāsayogāt sa ca sundarīṇām // 27 // 

nāmnāpi tasya viṣamā garalāḥ prayānti nāgāḥ phaṇīndrakiraṇāḥ śakulā bhavanti // 
vidyāmadoddhatabalān viduṣo ˈpy avācaḥ kurvanti vākyavibhavena japena yuktāḥ // 28 // 

vidyādharān gajaturaṅgamapṛṣṭharūḍhān prauḍhāṅganāparijanena nigūḍhakaṇṭhān /
vidyābalair jayati mantravidāṃ variṣṭho niṣṭhākṛtā manasi rājyasukhāni bhoktā // 29 // 

kāmād ratiṃ girisutāṃ giriśāt tathaiva nārāyaṇāc chriyam akhaṇḍalakāc chacīṃ ca /
vācaspater amalagīśvariṇīṃ ca śuklāṃ mantrair vijitya dharaṇīṃdharato ˈpi lakṣmīm // 30 // 

nānānidhānadhanakuṇḍalahemaraupyaṃ vastrādikaṃ draviṇajātanibaddhacittaḥ /
cittena sarvam akhilaṃ parikṛṣya bhuṇkte mantrānvito bhagavatīṃ paribhāvayed yaḥ // 31 // 

rājyaṃ nṛpāt phalam atīndriyakaṃ ca vṛkṣāt toyaṃ nadīnadasamudragataṃ vikṛṣya /
mantrānvitaḥ pibati khādati mantrapūtaṃ mantraṃ vinā na hi jitā khalu bhogasiddhiḥ // 32 // 

vanyān gajān varaturaṅgamajanmajātān bhogānvitān phaṇivarān garaloddhatāṃś ca /
nakrebhaṛkṣadvipino ˈpy atha gaṇḍakāṃś cākṛṣṭvā svamantrabalasāhasakena mantrī // 33 // 
ārohate vigatavismayalocanena maitrīdṛśā yadi sa paśyati mantrasiddhaḥ // 34 // 

kṛpādṛśā yadi vilokayatīha lokān duḥkhād viyogakuṭilād viṣamāt sa mantrī /
uttārya lokam akhilaṃ hi karoti śāntiṃ cintāmaṇir bhavati lokahitāya tārā // 35 // 

mārān vijitya variṣec ca nidhānavṛṣṭiṃ kalpāṅghrirūpyam avatārya janāya dadyāt /
vittaṃ dhaneśvaragataṃ nikhilaṃ vikṛṣya saṃpādayet sakalalokahitāya pākaṃ // 36 // 

vastraṃ tathā kṛpaṇalokasamastahetoḥ pīṭhaṃ gṛhaṃ chadam apīha bhavec ca tārā /
āpatsu sarvaduritāpaharā bhavec ca setur vipannavaṇijāṃ ca samudramadhye // 37 // 

tāṃ tārāṃ bhāvayed yogī prathamaṃ duḥkhitāyate /
tām upāsya dinenaiva bhojyalābhī bhaven naraḥ // 38 // 

dvitīye vastralābhī syāt yoṣitāṃ saṅgamas tataḥ /
tatas tāmbūlabhoktā ca ayācitaṃ yathepsitam // 39 // 

yadi syād brahmacārī tu bhuṅkte kanyāṃ surāgrajāṃ /
sattvānāṃ māraṇe raktā na sidhyantīha śāsane // 40 // 

daśakuśalarato bhūtvā mahāyānaikacittakṛt /
sa bhuṅkte vipulāṃ siddhiṃ vajradharmavaco yathā // 41 // 

paṭāvatāraṇakalpaḥ prathamaḥ

Chapter 2

athātaḥ saṃpravakṣyāmi yena tuṣyanti dharmatāḥ /
dharmapūjāprayogeṇa dharmadhātuḥ svayaṃ bhavet // 1 // 

athātaḥ kalpavṛkṣasādhanaṃ bhavati // 

vṛṃkārākṣarasaṃbhūtaṃ kalpavṛkṣaṃ vibhāvayet /
utpalasya parāvṛttyā vṛkṣaṃ vāmena bhāvayet // 2 // 

nānādhanamahāvṛṣṭiṃ varṣayantaṃ nabhastalāt /
arthināṃ pūrayed āśām iti dhyātvā dhaneśvaraḥ // 3 // 

caturdvīpagatān sattvān ākṛṣya cittaraśminā /
tebhyo dānaṃ pradātavyaṃ saptaratnamayaṃ sadā // 4 // 

pariṇāyakamahāratnaṃ ratnaṃ sāmudrikaṃ tathā /
strīratnam aśvaratnaṃ ca khaḍgaratnaṃ tathaiva ca // 5 // 

ibharatnādiratnāni buddhebhyo manasā sṛjet /
strīratnam samalaṅkṛtya nānārūpāṃ vilāsinīṃ // 6 // 

buddhebhyo manasā deyā buddhatvaphalakāṅkṣiṇā /
anena sarvabuddhatvaṃ vidyādharaḥ samaśnute // 7 // 

mahākoṣeṇa saṃpūrṇaṃ pariṇāyakadhaneśvaram /
buddhebhyaḥ sādaraṃ dadyād buddhatvaphalakāṅkṣayā // 8 // 

evam anyāni ratnāni sādareṇa parityajet /
vajradharmatvam ābhujya sarvasattvārthakṛd bhavet // 9 // 

kalpavṛkṣasādhanam // 

cetasā sarvabuddhatvaṃ cetasaiva vimucyate /
cetasā mokṣate bandhaṃ cetasā muktimān bhavet // 10 // 

cittaṃ hitvā padārthānāṃ sthitir anyā na dṛśyate /
buddhatvaṃ siddhayaḥ sarvā yad utānyā vibhūtayaḥ // 11 // 

bhājanā jaṅgamā ye tu bhūtabhautikasaṃbhavāḥ /
jñānamātrā iti khyātā vipaścidbhir nirāsravaiḥ // 12 // 

tasmāt sarvaprayatnena cittādarśaṃ tu mārjayet /
prakṛtyāgantavo doṣāḥ prahīyanta iti kramāt // 13 // 

nirmalaṃ pūrṇacandrābham ādisvarasamudbhavam /
cittacandraṃ vibhāvitvā bījaṃ tasyopari nyaset // 14 // 

ūṣmāṇāṃ ca caturthaṃ tu agnivarṇopari sthitam /
īkāreṇa samāyuktam ākāśadvayabhūṣitam // 15 // 

tasya citramayūkhābhiḥ kṛtvā nirmalinaṃ jagat /
sahādidhātukaṃ śodhya kurukullaparvate gatām // 16 // 

saṃcodya ca tathā tārām ānayitvā puraskaret /
tasmād bījān mahāpūjāmeghān saṃsphārayed budhaḥ // 17 // 

puṣpadhūpatathādīpagandhanaivedyasaṃcayaiḥ /
lāsyamālyanṛtyagītavādyapūjādibhis tathā // 18 // 

ratnatrayaṃ me śaraṇaṃ sarvaṃ pratidiśāmy agham /
anumode jagatpuṇyaṃ buddhabodhau dadhe manaḥ // 19 // 

idaṃ mantraṃ tridhā vācyaṃ tataḥ kṣantavyam ity api /
cittaṃ maitrīvihāre ca niveṣṭavyaṃ punas tadā // 20 // 

karuṇācittam utpādya pramodacittam āvahet /
paścād upekṣate sarvaṃ cittamātravyavasthayā // 21 // 

cittaṃ śūnyaṃ punaḥ kuryāt prākṛtākārahānaye /
śūnyatāvahninā dagdhāḥ pañcaskandhā ˈpunarbhavāḥ // 22 // 

oṃ śūnyatājñānavajrasvabhāvātmako ˈham /
muhūrtaṃ śūnyatāyogaṃ kuryāc cittasya viśramam // 23 // 

pratijñāṃ prāktanīṃ smṛtvā bījamātraṃ punaḥ smaret /
pratāritā mayā sattvā ekāntaparinirvṛtā // 24 // 

kathaṃ tān uddhariṣyāmi agādhād bhavasāgarāt /
iti matvā kṛpāviṣṭo niśceṣṭāṃ śūnyatāṃ tyajet // 25 // 
 
dharmadhātumayaṃ cittam utpādayati cetasā /
buddhādhiṣṭhānato bījam utpalākhyaṃ tato bhavet // 26 // 

utpale candrabimbaṃ tu akārasvaratodbhavam /
tasmiṃś candre punar bījaṃ tasmād gabhastayo gatāḥ // 27 // 

tābhir viśodhitā dhyeyā niḥśeṣā lokadhātavaḥ /
śodhya bodhya tathā sarvaṃ raśmibhir buddhakoṭayaḥ // 28 // 

viśantān bījakair dhyāyāt tatas tārodayo bhavet /
raktavarṇāyudhā devī sarvābharaṇabhūṣitā // 29 // 

samayamūrtim āsādya jñānacakraṃ samāhvayet /
jhaṭityākāraniṣpannaṃ jñānacakraṃ puraḥsthitam // 30 // 

samayamudrāyogena sukhamārge niveśayet /
pāṇibhyām añjaliṃ kṛtvā māṃsalau nāmitau yadā // 31 // 

dīrghābhyāṃ tu kṛtā sūcī sūcīmadhye tv anāmikau /
latābhyāṃ madhyamau śliṣṭau dvāv aṅguṣṭhāv adho gatau // 32 // 

anena bandhayet samayām anayā cakraṃ praveśayet /
tato ˈbhiṣekaṃ prārthayed buddhān iti gāthāṃ paṭhan kṛtī // 33 // 

bodhivajreṇa buddhānāṃ yathā datto mahāmahaḥ /
mamāpi trāṇanārthāya khavajrādya dadāhi me // 34 // 

te dadanti mahadbhūtā rājyam abhiṣekanāmataḥ /
puṣpābhiṣekavad rājñaḥ pañcabhir locanādibhiḥ // 35 // 

abhiṣekaṃ mahāvajraṃ traidhātukanamaskṛtaṃ /
dadāmi sarvabuddhānāṃ triguhyālayasaṃbhavam // 36 // 

buddhābhiṣekatas tārā dharmacūḍāmaṇir bhavet /
raktacitraprabhābhābhir dīpayantī jagattrayaṃ // 37 // 

prāptābhiṣekaratnas tu sarvasiddhiṃ prasādhayet /
varṣārddhaṃ tu dṛḍhāveśād yathoktavidhinā purā // 38 // 

trisandhyāsu baliṃ dattvā mantreṇānena śarkaraiḥ /
piṣṭakādyair vidhānena svapnābhijñānam āpnuyāt // 39 // 

khaḍgaṃ pātālasiddhiś ca antardhānaṃ rasāyaṇam /
adṛśyaṃ khecaratvaṃ ca pādalepāñjanaṃ tathā // 40 // 

svapnena pratyabhijñānaṃ siddhir utpadyate svayam /
kṣudrasiddhiṃ na sādheta yadi tārārato bhavet // 41 // 

cakravartipadaṃ rājyam indratvaṃ sārvabhoktṛtām /
svapnenaiva prasādheta jāpabhāvanayānvitaḥ // 42 // 

ṣaṇmāsāntaikamāsasya sarvāṃ rātriṃ japet kṛtī /
baddhvā caivotpalāṃ mudrāṃ yāvan mudrā jvalet kṣaṇāt // 43 // 

tena mudrāprabhāveṇa samākṛṣṭāḥ sayoṣitaḥ /
brahmendropendrarudrādyā āgacchanti vaśīkṛtāḥ // 44 // 

tataḥ prabhṛti sarvātmā siddhaḥ saṃsāravāsanāt /
yathā padmam asaṃliptaṃ paṅkadoṣeṇa vāriṇā // 45 // 

spṛṣṭaḥ sūto yathā naikaḥ saṃhṛte caikatāṃ vrajet /
tathā siddhasya cittāni sarvajñatvaṃ gatāni ca // 46 // 

siddhasūtena saṃspṛṣṭau yathā śulvo bhaven nidhiḥ /
mantrasūtais tathā spṛṣṭā buddhakāyā hi mantriṇaḥ // 47 // 

tridaśeśvaratāṃ yānti traidhātukamaheśvarāḥ /
buddhavaṃśe samutpannā dharmacakrapravartakāḥ // 48 // 

jātiṃ kurvanti pravrajyāṃ bodhimaṇḍopasaṃkramam /
caranti duṣkarāṃ caryāṃ buddhatāṃ ca smaranti te // 49 // 

devāvatāranirmāṇaṃ dharmacakrapravartanam /
parinirvāṇalābhaṃ ca śmaśāne gamanaṃ tathā // 50 // 

triloke dhātukaṃ hitvā saṃbhogair vigrahair jināḥ /
śuddhāvāsaṃ punar yānti hitvā nirmāṇajāṃ tanum // 51 // 

pravartya dharmakāyaṃ tu pustakādipaṭakramaiḥ /
sa eva sidhyate mantras tena buddhena bhāṣitaḥ // 52 // 

kurukullābhisamayakalpo dvitīyaḥ

Chapter 3

atha te sarvabodhisattvā ātmanaivātmacittaparivitarkam āpadya vajrapāṇiṃ mahābodhisattvam evam āhuḥ / kathaṃ vajrapāṇe buddhā bhagavanto vajrakāyā dharmadhātukāyāḥ abhedyakāyāḥ kasmiṃścit pṛthivīpradeśe kālakriyāṃ kurvanti //  atha khalu vajrapāṇis tān bodhisattvān evam āha / bodhisattvā mahāsattvā mā evaṃ procuḥ / kathaṃ buddhā vajrakāyā abhedyakāyā dharmadhātukāyāḥ kasmiṃścit pṛthivīpradeśe kālakriyāṃ kurvantīti / athāha vajrapāṇiḥ / tatraivaṃ śṛṇvata bodhisattvā yad bhagavān parinirvṛtaḥ sukhāvatyāṃ gataḥ // 1 // 

atha bodhisattvāḥ procuḥ / kiṃ vajrapāṇe buddhā bhagavantaḥ kāyaṃ prahāya sukhāvatīṃ gacchantīti / āha / āryakulaputrā nirmāṇakāyaṃ prahāya saṃbhogakāyena sukhāvatīṃ prayāntīti / bodhisattvā āhuḥ / tat kathaṃ vajrapāṇe kāyaṃ tyaktvā yāntīti / vajrapāṇir āha / yathā kaścin māyāvī puruṣaḥ prayojanārthaṃ māyām avatārya prayojanaṃ sādhayet // 2 // 

tathā buddhāḥ purāsiddhāḥ sattvānugrahahetunā /
punarjanmagrahaṃ cakruś cakravartini nirvṛte // 3 // 

yadā buddhā na santīha cakravartī tadā bhavet /
ubhābhyāṃ vigato loko na kadācid utpadyate // 4 // 

vineyaṃ lokaṃ āsādya vinītvā dvipadottamāḥ /
saṃsthitvāśītivarṣāṇi yayur buddhā jinālayam // 5 // 

buddhamāyāṃ parityajya sukhāvatyāṃ jinālaye /
mahāpraśamasukhāsaktās tiṣṭhanty ānandarūpataḥ // 6 // 

kartṛ nityaikabhoktāraṃ manyante ṛṣayo manaḥ /
evaṃrūpaṃ na tattvena kṣaṇikaṃ śūnyam iṣyate // 7 // 

ātmagrahavipannānāṃ nityaṃ nityārthakāṅkṣiṇām /
anityatāvatārāya tyaktvā kāyaṃ yayur jināḥ // 8 // 

teṣāṃ sarvajñacittānāṃ sarvabhāvasvabhāvinām /
itaḥsthānam ito'sthānaṃ niścitaṃ naiva vidyate // 9 // 

saṃvṛtisatyam āśritya buddhānāṃ dharmadeśanāḥ /
pravartante nabhastulyā vineyāḥ susahādiṣu // 10 // 

buddhotpādo na tattvena buddhanāśo ˈpi naiva ca /
sarvaiś caikarasībhūte notpādo na vyayas tathā // 11 // 

dharmadhātvekarūpās te pañcāvṛtivivarjitāḥ /
gambhīrodārarūpeṇa tasthus tattvasvarūpataḥ // 12 // 

sadasattvaṃ gatā naiva ubhayor apy asaṃbhavāt /
ādāv evāsvabhāvās te na niruddhā na bhāvinaḥ // 13 // 

bodhisattvāḥ procuḥ //  kathaṃ vajrapāṇe buddhā bhagavantas traidhātukaśāsino notpannā na niruddhā iti / vajrapāṇir āha / bodhisattvās tat kiṃ manyatha / yo yāvān buddhaḥ so ˈsan uta sann iti / bodhisattvāḥ procuḥ / vajrapāṇe buddhā na santo nāsantaḥ // 14 // 

vajrapāṇir āha /

ajena na hi jātavyaṃ jātasyāpi na codayaḥ /
tasmād ādāv anutpannāḥ paramārthavicāraṇe // 15 //
