Title: Maitreyaparipṛcchā    
Source: Vinītā 2010, no. 16
Tibetan: D 149 
Input: Péter-Dániel Szántó 

evaṃ mayā śrutam ekasmin samaye bhagavān rājagṛhe viharati sma gṛdhrakūṭe parvate mahatā bhikṣusaṃghena sārdhaṃ mahatā bodhisattvagaṇena | 

atha khalu maitreyo bodhisattvo mahāsattvas tasmin devaparṣanmaṇḍale saṃniṣaṇṇaḥ | sa utthāyāsanād ekāṃsam uttarāsaṅgaṃ kṛtvā dakṣiṇajānumaṇḍalaṃ pṛthivyāṃ pratiṣṭhāpya yena bhagavāṃs tenāñjaliṃ praṇamya bhagavantam etad avocat | 

ko 'tra bhagavan dharmadānasya vipākaḥ | 

evam ukte bhagavān maitreyaṃ bodhisattvaṃ mahāsattvam etad avocat | 

yaś ca maitreya gaṅgānadīvālukopamāṃs trisāhasramahāsāhasrāṃl lokadhātūn saptaratnaparipūrṇān kṛtvā dānaṃ dadyāt tathāgatebhyo 'rhadbhyaḥ samyaksaṃbuddhebhyaḥ, yaś caikagāthāṃ kāruṇyāt parasaṃtāne pratiṣṭhāpayet, asya maitreya puṇyaskandhasyāsau pūrvakaḥ puṇyaskandhaḥ śatatamīm api kalāṃ nopaiti | sahasratamīm api śatasahasratamīm api koṭītamīm api koṭīśatatamīm api koṭīsahasratamīm api koṭīśatasahasratamīm api saṃkhyām api kalām api gaṇanām apy upamām api na kṣamate |
	% °sāhasrāṃl] em., °sāhasrāl ed.
	% kalāṃ nopaiti] em., kalān nopaiti ed.

idam avocad bhagavān | idam uktvā sugato hy athāparam etad uvāca śāstā |

yaś ceha gaṅgāsikatopamāṃs tān ratnasya pūrṇān varalokadhātūn | 
dadyād jinebhyo muditaḥ sucittā yaś caikasattvāya deśayeta gāthām || [1]

tad ratnadānaṃ vipulaṃ hy atīva gāthāpradānasya kṛpārjitasya | 
prāpnoti kāṃcin na kalāṃ na saṃkhyāṃ dvayos trayāṇāṃ kuta eva cintā || [2]

idam avocad bhagavān āttamanā maitreyo bodhisattvo mahāsattvas te ca bodhisattvāḥ sadevamānuṣāsuragandharvaś ca loko bhagavato bhāṣitam abhyanandann iti |

āryamaitreyaparipṛcchānāmamahāyāsūtraṃ ṣoḍaśamaṃ samāptam |
