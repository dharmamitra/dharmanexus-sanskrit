subauddhasya suprabuddhasya śiṣyasya guṇaśālinaḥ /

gurubhaktasya dakṣasya tantrarājaṃ pradarśayet // (1) //
[8b]oṃ namo vimalacandrāya devaputrāya satyena dhriyate lokaḥ satyena parigṛhyate /
satyena dharmasthito lokaḥ satyaṃ brahmasanātanam /
satyaṃ buddhaś ca dharmaś ca saṃghaś ca guṇasāgaraḥ /
anena satyavākyena kṣipram āviśa darpaṇe /

tadyathā /
oṃ sara sara siri siri suru suru merumandarapratīkāśa āviśa āviśa kailāsakūṭaputrāya namaḥ /
yad mayā cintitaṃ kāryaṃ tat sarvaṃ brūhi tattvataḥ /
ātmārthaṃ parārthaṃ vā śubhaṃ vā yadi vāśubham //
prabhāte śucisthāne maṇdalakam upalipya kalaśaṃ sthāpayitvā pūjam udārāṃ kṛtvā darpaṇam abhimantrya susnātaṃ sudhautavastrāvṛtaṃ śvetacandanaliptāṅgaṃ sugandhikusumāvṛtakaṇṭhaṃ dārakaṃ dārikāṃ vāvinaṣṭāṃ grāmyadharme pradarśayet /
yathācintitakāryam avitatham āvedayati /
sāyāhne śiraḥsthāne maṇḍalakaṃ pralipya bhagavato vimalacandrasya devaputrasya mahatīṃ pūjāṃ kṛtvāṣṭottaraśatam āvartya maunena svapet /
yathācintitakāryaṃ śubhā-
%p.5
śubham āvedayati /
satataṃ japatāṃ trilokacaritāni vastūni kathayati // 20 //
oṃ śravaṇapiśācini muṇḍe svāhā //
vibhītakavṛkṣasya vaṭavṛkṣasya vādhastāt sthito maunī lakṣam ekaṃ japet siddho bhavati /
lokatrayacaritaṃ karṇe kathayati /
atha vā snātaḥ śucivastrāvṛtaḥ pracchanne 'yutam ekaṃ japet /
tataḥ siddho bhavati /

rātrau kuṣṭham aṣṭaśatābhimantritaṃ kṛtvā svamukhaṃ pādau cābhyaṅgyānālapan svapet svapne śubhāsubhaṃ kathayati // 21 //
oṃ namaḥ saptānāṃ samyaksaṃbuddhakoṭīnām /
tadyathā /
oṃ cale cule cunde mahāvidye satyavādini varade kathaya kathaya svāhā //
pūrvoktavidhānenādarśe śaṅkhe pradīpe jalabhājane vā kathayati /

aṣṭottaraśatābhimantritajalena mukhaṃ prakṣālya maunī svapan svapne śubhāśubhaṃ vā paśyati // 22 //
oṃ mucili svāhā /
mohani svāhā /
dantili svāhā // 
mantro 'yam ayutajaptaḥ siddho bhavati /
āryāvalokiteśvarasya bhagavato mahatīṃ pūjāṃ kṛtvāṣṭottaraśatābhimantritajalena mukhaṃ prakṣālya kāryaṃ manasi kṛtvā japan svapet /
anālapan svarūpeṇa bhagavantaṃ paśyati /
śubhāśubhaṃ ca suptam upalabhate // 23 //
oṃ prajvala hūṃ phaṭ //
hṛdayam idaṃ bhagavato lokanāthasya niyutam ekaṃ japtena sidhyati /
pūrvoktavidhānena śubhāśubhaṃ svapne kathayati // 24 //
%p.6
oṃ namaḥ saptānāṃ buddhānām apratihataśāsanānām /
tadyathā /
oṃ kumārarūpeṇa darśaya darśaya ātmano vibhūtiṃ samudbhāvaya svapnaṃ nivedaya yathābhūtaṃ hūṃ hūṃ phaṭ phaṭ svāhā // 
mañjuśrībhaṭṭārakasya paṭasya pratimāyā vāgrataḥ sadhātuke caitye vā 
yathāvibhavataḥ pūjāṃ kṛtvā saptaśatiko jāpaḥ kartavyaḥ /
svayaṃ svapnam upalabhataḥ paraṃ ca darśayet // 25 //
oṃ karṇapiśāci karṇe me kathaya hūṃ phaṭ // 
piśācataror adhastāt trailokyavijayasamādhisthas tatraiva vasanamaunī matsyamāṃsajambūlikām abhimantrya tasyā balim upasaṃhṛtya trisaṃdhyaṃ mantram āvartayet /
prathame divase nimittaṃ darśayati /
paścād āgacchati siddho bhavati /
tataḥ prabhṛti bhuvanatrayacaritaṃ karṇe kathayati /
trisaptāhād brahmaghnasyāpi sidhyati // 26 //
oṃ caturbhuja ṣaṇmukha vikṛtānana karṇapiśācīm ākarṣaya hūṃ phaṭ //
śmaśāne yamāntakapaṭasyāgrato japtavyam /
trisaptāhāt karṇapiśācī sidhyati // 27 //
oṃ buddha curu curu mārge svāhā // 
sadhātuke caitye buddhabhaṭṭārakasya purastāt pūrvasevāyutaṃ japtvā paścād yathāvibhavataḥ pūjāṃ kṛtvā śayanavelāyām aṣṭau śatāni japtvā kā me jātir āsīt kā punar bhaviṣyatīti manasā vicintya svapet /
svapne bhūtabhaviṣyajjātim upalabhate na saṃdehaḥ /
yadi ṣaṇmāsābhyāntare mṛtyur bhavati tadā grīvārahitam ātmānaṃ paraṃ vā svapne paśyati /
evaṃ darpaṇam abhimantrya paśya na dārakadārikāṃ vāyaṃ grīvārahitaṃ prekṣate tasya ṣaṇmāsābhyantare mṛtyuḥ /
srotāñjanaṃ śvetāgastyatarumūlaṃ ca vartiṃ kṛtvā cakṣur añjayed aṣṭaśatābhimantritena yeṣāṃ ṣaṇmāsābhyantare mṛtyur bhaviṣyati tān sarvān dvipadacatuṣpadāñ śirasā vinā pratyakṣaḥ paśyati // 28 //
%p.7
oṃ svapnavilokini siddhalocane svapnaṃ me kathaya svāhā // 
ayaṃ mantrarājaḥ pūrvoktavidhānāni sarvāṇi karoti // 29 //
oṃ aditi devadattāṃ me dehi dadāpaya svāhā //
jalamadhyagato yāṃ kanyām uddiśya japati sā tasyaiva dīyate /

akṣaralakṣajāpyaṃ kāryaṃ priyaṅgukusumahomena vā palāśakusumānāṃ lakṣahomena mahatīṃ śriyam āsādayati /
kṣīravṛkṣasamidbhir niśāyāṃ homena yaṃ grāmam uddiśya japituṃ labhate /
padmānāṃ bilvaphalānāṃ lakṣam ekaṃ kṛtvā rājavaṃśajo rājyaṃ labhate /
anyo mahatīṃ śriyaṃ prāpnoti /
yathālabdhakusumānāṃ saptalakṣāṇi kṛtvākṣayavibhavo bhavati // 30 //
oṃ jaye vijaye ajite aparājite svāhā //
caturbhaginīnāṃ hṛdayamantrarājo 'yaṃ caturlakṣajaptaḥ pūrvoktavidhānena pūrvoktāni karmāṇi karoti // 31 //
oṃ megholkāya svāhā //
palāśapuṣpaiḥ samidbhir vā lakṣam ekaṃ kṛtvā hemnāṃ lakṣaṃ labhate /
kanyārthī cābhipretāṃ kanyāṃ labhate // 32 //
oṃ kamalavikāsini kamale mahālakṣmi rājyaṃ me dehi varade svāhā //
mantro 'yaṃ mahālakṣmīhṛdayaṃ satataṃ japtaṃ vibhūtiṃ parāṃ dadāti /
yathālabdhakusumahomena mahatī śrīr bhavati /
abhipretāṃ kanyām āsādayati /
karpāsāsthipramāṇānāṃ gugguluguṭikānāṃ trimadhurāktānāṃ la.ksahomena padmānāṃ vā rājyam āsādayati // 33 //%p.8
oṃ nandini varade kiṇi kiṇi khiṇi khiṇi śriyaṃ me dada vauṣaṭ // 
ayaṃ mantrarājo nandinīhṛdayaṃ pūrvoktakarmakaraḥ // 34 //
oṃ jambhe mohe svāhā //
ayaṃ mantrarājaḥ karavīrakusumais tārābhaṭṭārikām abhipūjyākṣaralakṣaṃ japtāṃ manorathaṃ paripūrayati // 35 //
oṃ vasudhāriṇi svāhā //
oṃ śrīvasu svāhā //
oṃ vasuśriye svāhā //
oṃ vasumukhi svāhā //
oṃ vasumatiśriye svāhā //
ātmānaṃ jambhalarūpaṃ dhyātvā svahṛdaye candramaṇḍalamadhye vasudhārāṃ suvarṇavarṇāṃ dvibhujāṃ sarvālaṃkārabhūṣitāṃ pūrvādidigbhāge caturdevīparivṛtāṃ dakṣiṇe varadāṃ vāme dhānyamañjarīhastāṃ dhyāyan manorathaṃ paripūrayati /
gomayena maṇḍalakaṃ caturasraṃ dvihastapramāṇaṃ kṛtvā trisaṃdhyaṃ kusumair abhyarcya sahasracatuṣṭayaṃ jāpaṃ kurvatā ṣaṇmāsād manorathaṃ paripūrayati /
yathālabdhakusumānāṃ caturlakṣahomena mahatī śrīr bhavati /
akṣaralakṣaṃ japan mahatīṃ śriyam āsādayati /
gugguluguḍikālakṣaṃ kṛtvā manorathaṃ paripūrayati // 36 //
oṃ vasudhāriṇi amukīṃ kanyāṃ me dehi dadāpaya svāhā // 
niyamastho 'sya mantrasya catvāri lakṣāṇi jalamadhyagataḥ snātvā japann abhipretāṃ kanyāṃ labhate /
niśāsu kṣīravṛkṣasamidbhir grāmasya nāma gṛhītvā lakṣaṃ juhvan grāmaṃ labhate // 37 //
oṃ vasudhāriṇi svāhā //
oṃ candrakāntyai svāhā //
oṃ dattāyai svāhā //
oṃ vasudattāyai svāhā //
oṃ āryāyai svāhā //
%p.9
oṃ subhadrāyai svāhā //
oṃ guptāyai svāhā //
oṃ devyai svāhā //
oṃ sarasvatyai svāhā //
sauvarṇapattre rasjatapattre tāmrapattre vāṣṭadalakamalamadhye vasudhārāṃ pūrvādidigdaleṣu candrakāntyādimahāyakṣiṇīḥ pattradvayam abhilikhya saṃpuṭīkṛtya ghṛtamadhuśarkarāmadhye nikṣipya pūrvoktavidhānena pūrvoktāni kāryāṇi karoti // 38 //
oṃ jambhalajalendrāya svāhā //
oṃ māṇibhadrāya svāhā //
oṃ pūrṇabhadrāya svāhā //
oṃ dhanadāya svāhā //
oṃ vaiśravaṇāya svāhā //
oṃ diśi vidiśi svāhā //
oṃ keli malme svāhā //
oṃ vicitrakuṇḍaline svāhā //
oṃ sukhendrāya svāhā //
oṃ carendrāya svāhā //
aṣṭabhir mahāyakṣaiḥ parivṛto bhagavatyā ca vasudhārayā sahitaḥ suvarṇavarṇo nakulībījapūrakadharaḥ pralambodaraḥ sarvālaṃkārabhūṣitaḥ pūrvoktayakṣiṇīsahitā yakṣendrāś ca trailokyarājyam apt bhagavān dadāti /
trisaṃdhyam abhipūjya dhyāyatāṃ japatām aṣṭau śatāni jalaculukānāṃ vā prayacchatāṃ prātar akākarudite jalamadhyagato yo japati tasyākṣayadhanasamṛddhir bhavati /
atha vā suvarṇādipātre vasudhārāṃ yakṣiṇīsahitāṃ dvitīyapātre bhagavantaṃ jambhalaṃ yakṣaiḥ parivṛtam ālikhya saṃpuṭīkṛtya dhārayet /
aṣṭau mahāsiddhīr dadāti /
kiṃ punar anyāḥ siddhayaḥ //
siddhaikavīramahātantrarāje dvitīyaḥ paṭalaḥ //
