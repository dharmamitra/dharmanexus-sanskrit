oṃ namaḥ śrīvajrayognyai.

nṛtyadhyānaṃ prakurvan murajamukharavāhūtadevair natāṃgrir
bhaṅgavyāsaktagātras tad anu vigaṇitasthānakaṃ nyastapādaḥ /
bhrūbhaṅgollokhinetrānugavalitabhujavyūhahastāṅulībhir
mudrābandhapravṛttiḥ kramavalitamukho hantv aghaṃ heruko vaḥ //

prāyo janaḥ śocyatamo 'tiduḥkhibhūyāṃsam ālokayituṃ na śaktaḥ /
asas tu saṃskṣiptavidhiṃ vidhāsye vipaddhatiṃ paddhatim ātmaśaktyā //
kṛto na cābhimānena kriyāsamuccayo mayā /
kṣantavyaṃ paṇḍitaiḥ sarvair yad atra padadūṣaṇam //
nānātantrāt samākṛṣya nānācāryamatād api /
likhyate darpaṇeneha samantādhyeṣaṇāvaśāt //
pratiṣṭhādikriyāḥ sarvā vajrācāryapuraḥsarāaḥ /
tasmāl lokahitārthāya tasya lakṣaṇam ucyate //

[II]a.
tatrādau tāvad vajrācāryalakṣaṇam āha.
laukikalokottarācāraṃ darśayatīty ācāryaḥ.
athavā, ārād dūraṃ pāpakebhyaḥ dharmebhyaś caratīty ācāryaḥ, niruktavidhinā sādhanīyaḥ.

yad vā vajramārgadeśakācāryo vajrācārya iti.

vajraśabdaviśeṣaṇena trivajrābhedyatvaṃ pratipādyate.
sa ca kathaṃ bhūtaḥ?

lābhālābhayaśoyaśovirahito nindāpraśaṃsājitaḥ
śāṃtāśāṃtanirodhavardhitamatiś cotsāhayuktaḥ kṛtī /
kāruṇyākulamantranītirasiko nirmatsaro nispṛhas
tattvajñānalabdhaḥ pratiṣṭhamatimān ācāryarājaḥ sadā //

sa cottamādibhedena trividho bhavati.
tadyathā
ācāryas trividhas tantre yathoktaṃ saṃvarārṇave /
gṛhasthaḥ śrāmaṇerākhyo bhikṣuś ceti tridhā bhavet //
uttamo bhikṣur ācāryo yasmād uktaṃ tathāgataiḥ /
madhyamaḥ śrāmaṇerākhyo gṛhasthas tv adhamo mataḥ //
prāptadaśābhiṣeko hi śrāmaṇeras tu madhyamaḥ /
agrābhiṣekalabdho hi bhikṣur uttamo vajradhṛk //
pañcakṣikṣāpadaprāpto daśaśikṣāpadair yutaḥ /
koṭiśikṣāpadaprāpto na te tulyās trayaḥ smṛtāḥ //

koṭiśikṣeti paryantāvasthāśikṣaṇād yuganaddhasamādher abhyāsāt.
uttame vidyāmāne tu nārādhyā anyamantriṇaḥ /
satsu triṣv ekadeśeṣu gṛhasthaḥ pūjyate yadā //
tadā buddhaś ca dharmaś ca saṃgho gacchaty agauravam //
iti.

yasmād agrābhiṣekalabdhas tasmād daśabhikṣusamaḥ.
uktaṃ paramārthasevāyām ---
